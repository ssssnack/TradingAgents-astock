# A 股多角色分析 Skill（独立分享包）

一套不依赖任何 Git 仓库的 A 股分析框架。  
对方只要有能对话的 Agent（Cursor / Claude / ChatGPT 等）即可使用。

## 设计原则

- **零安装**：不要求 clone、pip、Docker  
- **零 Key**：不要求配置任何 LLM / 行情 API Key  
- **靠 Agent 自身能力**：联网检索、阅读公开信息、用户粘贴数据  
- **可执行输出**：阶段判断 + BUY/HOLD/SELL + 价位计划  

## 包内文件

| 文件 | 给谁用 |
|------|--------|
| `SKILL.md` | 丢进 Cursor / Claude Code 的 skills 目录，让 Agent 自动按框架分析 |
| `PROMPT.md` | 纯文本提示词，复制到任意聊天窗口即可 |
| `README.md` | 本说明 |

## 如何分享给别人

任选一种，**都不必附带整个项目仓库**：

1. **最简单**：只发 `PROMPT.md` 里的提示词正文  
2. **推荐**：打包本文件夹（三个文件）发给对方  
3. **Cursor 用户**：让对方把 `SKILL.md` 放到自己的 skills 路径  

对方打开后直接说：

```text
按 a-stock-analysis 分析 603203，并给出后续操作
```

或把提示词里的 `{股票}` 换成代码。

## 对方需要准备什么？

| 需要 | 不需要 |
|------|--------|
| 一个能对话的 AI Agent | Git 仓库 |
| （可选）Agent 能联网查行情 | pip / 本地环境 |
| （可选）自己粘贴行情财报 | API Key、Web 长报告 |

## 示例问法

- 分析 002407，后续怎么操作  
- 603203 今天最佳出货价  
- 广誉远回踩多少适合入手  
- 对比 600771、002241、000021 哪只更适合建仓
